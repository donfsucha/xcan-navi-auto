# 출퇴근 자동실행 앱

집/회사 주소와 출근/퇴근 시간대를 저장한 뒤, 실행 버튼을 누르면 음악 앱을 먼저 열고 Android 미디어 재생 버튼 이벤트를 보낸 다음 선택한 내비 앱을 실행하는 Android MVP 앱입니다.

## 현재 구현된 기능

- 기존 참고 화면을 반영한 다크 운전용 홈 화면
- 홈/설정 하단 탭 구조
- Google Maps 기반 탐색 탭
- 지도 터치로 집/회사 좌표 자동 입력
- 큰 현재 시간 표시
- 드라이브 시작 버튼
- 현재 자동화 시퀀스 표시
- 집 주소 저장
- 회사 주소 저장
- 집 주소와 좌표 저장
- 회사 주소와 좌표 저장
- 집 좌표 지도 확인 및 확인 완료 상태 저장
- 회사 좌표 지도 확인 및 확인 완료 상태 저장
- 출근 시간대 저장
- 퇴근 시간대 저장
- 내비 앱 선택
  - 티맵
  - 카카오내비
  - 네이버지도
- 음악 앱 선택
  - 삼성뮤직
  - 멜론
  - 유튜브 뮤직
  - 스포티파이
- 음악 앱 실행
- `MEDIA_PLAY` 또는 `MEDIA_PLAY_PAUSE` 미디어 버튼 이벤트 전송
- 자동 판단 실행
  - 출근 시간대: 회사로 실행
  - 퇴근 시간대: 집으로 실행
  - 주말모드: 목적지 없이 내비 앱 실행
- 수동 실행
  - 회사로 가기
  - 집으로 가기
  - 주말모드 실행
- 선택한 외부 앱이 설치되어 있지 않으면 Play Store 화면 열기

## 프로젝트 열기

1. Android Studio에서 이 폴더를 엽니다.
2. Gradle Sync를 실행합니다.
3. Android 기기 또는 에뮬레이터를 선택합니다.
4. `app` 구성을 실행합니다.

## API 키 준비

실제 키는 코드에 직접 넣지 않습니다. `local.properties.example`을 참고해 `local.properties`에 아래 값을 추가하면 앱의 `탐색` 탭에서 준비 상태가 표시됩니다.

```properties
KAKAO_NATIVE_APP_KEY=
NAVER_MAP_CLIENT_ID=
TMAP_APP_KEY=
GOOGLE_MAPS_API_KEY=
```

자세한 내용은 [API_SETUP.md](API_SETUP.md)를 참고하세요.

## 빌드 환경

- Android Gradle Plugin: `8.7.3`
- Compile SDK: `35`
- Min SDK: `26`
- 언어: Java
- 외부 런타임 라이브러리: 없음

## 동작 순서

```text
홈
 -> 드라이브 시작
 -> 음악 앱 실행 요청
 -> 내비 앱 실행 요청
 -> 설정된 대기 시간 후 미디어 버튼 이벤트 전송

설정
 -> 집/회사 주소와 좌표 입력
 -> 지도에서 확인
 -> 확인 완료
 -> 저장

탐색
 -> 집 위치 선택 또는 회사 위치 선택
 -> 지도에서 원하는 위치 터치
 -> 위도/경도 자동 입력
 -> 선택한 좌표 확인 완료
```

```text
주소 입력
 -> 위도/경도 입력
 -> 지도에서 확인
 -> 확인 완료
 -> 설정 저장
 
실행 버튼
 -> 설정 저장
 -> 출근/퇴근/주말 모드 판단
 -> 선택한 음악 앱 실행 요청
 -> 선택한 내비 앱 실행 요청
 -> 설정된 대기 시간 후 미디어 버튼 이벤트 전송
```

## 현재 제한사항

- 이 MVP는 사용자가 앱 안에서 실행 버튼을 누르는 흐름을 기준으로 합니다.
- 음악 자동 재생은 Android 미디어 버튼 이벤트를 보내는 방식이라, 음악 앱과 OS 상태에 따라 실패할 수 있습니다.
- 네이버지도는 공식 `nmap://` URL Scheme으로 검색 또는 지도 실행을 시도합니다.
- 집/회사 좌표가 저장되어 있으면 네이버지도는 `nmap://navigation?dlat=...&dlng=...` 방식으로 목적지를 바로 전달합니다.
- 카카오내비를 선택하면 Kakao Navi SDK의 `navigateIntent()`로 저장 좌표를 전달합니다.
- 카카오내비 연동은 `KAKAO_NATIVE_APP_KEY`가 입력되어 있어야 동작합니다.
- Android의 백그라운드 화면 실행 제한을 피하기 위해 음악 앱과 내비 앱 실행 요청은 버튼 클릭 직후 연속으로 보냅니다. 미디어 재생 버튼 이벤트만 설정된 시간만큼 늦게 전송합니다.
- 네이버지도 앱에서 검색 결과를 선택한 사실을 이 앱으로 자동 반환받는 URL Scheme은 제공되지 않습니다. 그래서 현재 MVP는 앱 안에 위도/경도를 저장하고, 저장된 좌표로 길안내를 실행합니다.
- 티맵은 우선 표준 `geo:` Intent로 좌표 실행을 시도하고, 실패하면 앱 자체를 실행합니다.
- 정확한 길안내 시작은 앱별 공식 SDK 또는 좌표 기반 URL 연동을 추가해야 더 안정화됩니다.
- 현재 주소 검색어를 좌표로 자동 변환하는 기능은 포함되어 있지 않습니다. 대신 탐색 탭에서 지도를 터치해 좌표를 자동 입력할 수 있습니다.

## 다음 개발 단계

1. 실제 Android 기기에서 음악 앱별 미디어 버튼 반응 테스트
2. 티맵/카카오내비/네이버지도 목적지 전달 방식 검증
3. 주소 검색어를 좌표로 자동 변환하는 기능 추가
4. 앱별 공식 SDK 또는 URL Scheme 연동 보강
5. 차량 블루투스 연결 감지 후 알림 실행 기능 추가
